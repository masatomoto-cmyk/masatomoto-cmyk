## 🎛 What I do

DTM（パソコンで作る音楽）が好きで、**音楽制作の「面倒」をコードで減らす**ことを続けています。
音楽サイトの運営、機材・DAW をつなぐ Python ツール、学習中の Web アプリを作っています。
